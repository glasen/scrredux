# Developing SCR Redux

Single C program on SDL3 + SDL_GPU. Flat-shaded polygons, no textures, SPIR-V shaders only (Vulkan; MoltenVK on macOS).

## Build

```bash
make
```

Builds `./scrredux` from `src/main.c` and compiles `shaders/*` to `*.spv` with `glslangValidator`. Run from the project
directory: shaders, model and sounds are loaded from next to the binary.

The game is a single translation unit: `src/main.c` lists every module in dependency order, and a module may use
anything included above it. Files hold `static` code, so there is nothing to link and no header/source pairs.

## Source layout

Everything is under `src/`, one directory per concern:

| Directory | Contents |
| --- | --- |
| `main.c` | The include list (dependency order) and `main()` |
| `config/` | Constants by topic: `render`, `physics`, `track`, `palette`, `game`, `audio`, `ui` |
| `core/` | Vectors and maths, colour mixing, 3x4 matrices, vertex buffers and triangle emitters, boxes and cylinders |
| `physics/` | Tunable vehicle parameters and their defaults (`phys_defaults()`), steering, contacts, `car_step()` |
| `car/` | The `Car` type, damage, placement, pose; `model_*` load `models/stuntcar.scm` and pose suspension and steering |
| `ai/` | The computer driver, and jump planning with a scratch car |
| `track/` | Road segments, tracks as pieces on the 16 x 16 grid, player track files, geometry building, queries; `data/scr_tracks.h` holds the eight originals (generated) |
| `world/` | Deck mesh, support towers, the static vertex buffer |
| `scenery/` | Stadium, arena floor, props, service vehicles, sponsors, surroundings |
| `game/` | State machine, races and laps, model viewer, game tick, cameras |
| `league/` | Racing season, standings, saves, Hall of Fame |
| `replay/`, `settings/`, `input/` | Replays (60 Hz), volume/fullscreen/rumble options, key bindings, gamepads |
| `audio/` | Sample mixer, and when sounds trigger |
| `effects/` | Particles |
| `render/` | Font (`font_vec.h` is generated), SDL_GPU setup and upload, frame rendering, cockpit, flames, sky |
| `ui/` | HUD primitives and text, race HUD, `menu/` (screens, widgets, input, race preview, pause menu) |
| `editor/` | Track builder |
| `app/`, `platform/`, `util/` | Headless modes and input glue, file paths, PNG writer |
| `tools/gen_scr_tracks.py` | Generates `src/track/data/scr_tracks.h` |
| `tools/gen_font.py` | Generates `src/render/font_vec.h` from `fonts/Rajdhani-Bold.ttf` |

## Tracks

`track/data/scr_tracks.h` is generated by `tools/gen_scr_tracks.py` from a checkout of the Stunt Car Racer remake
([StuntCarRacer-X](https://github.com/Team-Resurgent/StuntCarRacer-X)), built from the original's road tables at the
scale the physics is tuned to: 128 original units = the 2.95 m wheelbase, 8.85 m deck width.

- Banked bends; sheer faces are solid walls with red/white end panels; the track stands on red/white girders.
- No barriers on the track edges. Past the edge the wheels find an invisible sloping shoulder for a moment, like the
  original.
- Draw Bridge's bridge does not move.
- The jumps are reshaped for the 250 km/h limit (`TRACK_EDIT`, `TRACK_HILL` in `track/original_edits.h`): steeper lips, shorter
  pits, Ski Jump's drop and High Jump's far side as landing hills, High Jump's tower lower. The builder opens the
  originals as copies with these edits baked in.
- `./scrredux --check-tracks` checks the originals against the builder's joining and overlap rules.
- The track builder (`editor/`) works in the stadium: `ed_build_scene()` builds the stadium once round the whole grid
  (`scene_builder`: no track, the grid drawn on the floor, no infield clutter), and the track goes into its own vertex
  buffer (`tkb`, uploaded as `vbuf_t`), rebuilt 0.08 s after a change. An open track is built with `trk_open`: its
  open end added, the stretch back to the start marked as a gap, no start line on the road. Ghosts, the selection and
  the joint poles are drawn each frame from the pieces' cross-sections (`ed_draw3d()`); clicks pick the deck by ray.

The player's files live in SDL's pref folder (`user_path()` in `platform/paths.h`, org and app both "SCR Redux"), or in
`$SCR_HOME` when that is set: `tracks/NAME.trk`, `options.txt`, `controls.txt`, `halloffame.txt`, `replayN.rpl`, and
the season as `season0.txt` (slots 1-4 for Load/Save). Seasons are text, a keyed line per item (`season_write()` /
`season_peek()` in `league/saves.h`): unknown lines are skipped, so a later version can add fields and still read old saves,
and a save missing a driver or a fixture is refused. Writes go to a `.tmp` file renamed over the old one.
Point `SCR_HOME` at a scratch folder when testing, so test runs leave the real saves alone.

## Physics

The car is a rigid body: four spring/damper suspensions with progressive hydraulic bump stops, tyre friction (traction
circle), weight transfer, full 3D rotation, solid deck collisions and car-to-car contact. The engine cuts out at
200 km/h, 250 km/h on boost (boost adds pull up to there, like the original's cut-off). Constants are in
`phys_defaults()` (`physics/defaults.h`).

Damage: a crack grows along the cage's top tube; at 100 the car is wrecked. Big hits punch holes at the original's
ten fixed spots (`hole_at()` in `car/car.h`: 12 of the crack's 240 pixels wide, every 24, filled from the right end).
The crack crosses a hole for free, so each hole brings the wreck 5% closer. In a season the holes carry over from race
to race (`Season.nholes`) and are cleared when a new season starts; once all ten are made, big hits only creak.

An 8 m catch net on the arena wall stops a car that leaves the track before it reaches the stands. It gives a few metres
and holds the car (counted as a crash); only a car flying higher than the net goes over it.

## AI

- **Jump planning:** when a track loads, a scratch car tries take-off speeds for every jump with the real physics; the
  AI takes the fastest one that lands clean on either side of the deck and boosts up to it when needed. The builder's
  J key runs the same planner.
- The opponent keeps clear of the player.
- Season races between two computer drivers are not simulated: the result comes from their pace on the track, with the
  odd fall and wreck.

## Crane recovery

Cranes lower both cars onto the track before the start and put a car back after it falls off: onto the middle of the
section it was last on, or the nearest one before it that is not a bend, not on the original's no-drop list and not in
a jump's run-up. A car that lands beside the track crashes in a cloud of dust and smoke (seen from outside) before the
crane picks it up.

## Rendering

- Native window resolution, 4x MSAA when supported.
- Sun shadows: two shadow-map cascades (near/far) covering track, towers, stands, trucks, cranes and cars.
- Scenery (`scenery/`): roofed grandstands with a VIP tier, open end terraces, crowd, sponsor boards, scoreboard,
  lattice floodlights, service gate; outside, car parks, trees, big-top tents and faceted mountains under drifting
  clouds. The arena floor is grass with mowing stripes, dirt worn under the track and a gravel service road to a
  compound (recovery truck, water bowser, ambulance, TV truck, cabins, containers); TV towers, marshal posts, tyre
  stacks and hay bales around.
- The deck is weathered concrete in precast slabs with rubber laid down in the bends; steel scraping it throws sparks.
- Text, on the HUD and on signs in the world, is Rajdhani Bold drawn as flat triangles, smoothed by MSAA (no textures).
  `render/font_vec.h` holds printable ASCII with the cap height as 1. Regenerate it with
  `tools/gen_font.py fonts/Rajdhani-Bold.ttf > src/render/font_vec.h`, which reads TrueType outlines without fontTools.
  Text sizes are still given in the old 5x7 font's pixels (`sc`): capitals are `7 * sc` tall with their top at `y`.
- The HUD pass has its own fragment shader (`shaders/hud.frag`) and blends by vertex alpha (`hud_a`): soft shadows and
  translucent plates in the menus.

## Car model

A single-seat tube-frame buggy: roll cage, exposed V8 with eight chrome zoomie pipes, double-wishbone suspension on all
four wheels, steering rig. The game loads `models/stuntcar.scm` (~32k triangles, shared by both cars, paint tinted per
car) and does not start without it.

`stuntcar.scm` is exported from the low-poly Blender model `models/stuntcar.blend` (also exported as
`models/stuntcar.glb`). `car/model_pose.h` poses wishbones, uprights, coilovers
and links from the physics' wheel travel and steering.

The model is built by a script, so it can be rebuilt with Blender 5.x (from the repository root):

```bash
LOWPOLY=1 blender -b --factory-startup -P models/scripts/build_car.py -- models
blender -b models/stuntcar.blend -P models/scripts/export_game_model.py -- models/stuntcar.scm
```

| Script | Does |
| --- | --- |
| `models/scripts/build_car.py` | Builds the car procedurally and writes `stuntcar.blend` and `stuntcar.glb`; `LOWPOLY=1` gives the faceted game version, without it the detailed one for renders |
| `models/scripts/export_game_model.py` | Writes `stuntcar.scm`: flat-coloured triangles in groups, the suspension rig (swept from the wishbone geometry to the bump stops and full shock extension), contact points, exhaust flames, the cockpit camera |
| `models/scripts/render_views.py` | Cycles stills from the model's cameras |
| `models/scripts/anim_suspension.py` | A video of one axle working through its travel (`--steer`, `--stills`, `--check` for contact tests) |

A rebuild gives the same rig and physics data and the same triangles, in a slightly different order.

`./scrredux --view` opens the model viewer; Z stops the animation (wheels straight, at ride height).

## Sound

The original Amiga samples in `sounds/`, taken from the remake's `Sounds/` folder, played where the original plays
them: the engine (TickOver and its decimated copies, revs model ported from the original), scraping, dirt, hard
landings, car-to-car hits, creaks and the smash that punches a hole in the cage tube; Chime counts down the start.
Engine and smash are panned left, the rest right, 30% apart. Without the WAVs the game runs silent.

## Debug tools

| Command | Purpose |
| --- | --- |
| `./scrredux --sim SECS [TRACK]` | Autopilot run, prints lap/damage/contact stats |
| `./scrredux --shot out.png SECS [TRACK] [CAM]` | Offscreen 1080p render. CAM: 0 chase, 1 cockpit, 2 front, 3 side, 4 model viewer, 5 track overview |
| `./scrredux --audio-dump out.wav SECS [TRACK]` | Mixes the autopilot's race into a WAV |
| `./scrredux --menu-frames DIR SECS` | Records the menu scene at 60 fps as PNGs |
| `./scrredux --ui-shot out.png "KEYS"` | Plays SDL key names through the menus and builder headless, renders the last frame |
| `./scrredux --check-tracks` | Checks the original tracks against the builder's rules |

`--ui-shot` script tokens: SDL key names (`.` and `,` for those keys), `shift+`, `ctrl+` and `alt+` prefixes in any
order (`ctrl+shift+Z`), `wait5` (run five seconds of the game), `text:Name` (type into a name field). In the track
builder also `click:X,Y` (a left click at HUD coordinates, 480 wide at 16:9 and 270 high; `click:X,Y,3` right) and
`fly:X,Y,Z,YAW,PITCH` (put the camera there, angles in degrees). Ending in the builder, it prints the track checked by
the builder's rules (joins, overlaps), the selection, the undo depth, the selected joints, the camera and where on
screen each ghost is.

| Variable | Effect |
| --- | --- |
| `SCR_DEBUG=1`, `SCR_TRACE=1` | Extra logging |
| `SCR_PLANE=x` | Autopilot lane (outside ±4.4 it drives off the track) |
| `SCR_WHEELS=1` | Reports the gap between the drawn tyres and the road |
| `SCR_CAM=px,py,pz,tx,ty,tz` | Free camera position/target for `--shot` |
| `SCR_SND=1` | Logs every sound as it starts |
| `SCR_NOHUD=1` | Hides the HUD (`--menu-frames`) |
| `SCR_AUTO=1` | Autopilot drives (`--ui-shot`) |
| `SCR_OVERVIEW=1` | Looks at the whole track from above (`--ui-shot`) |
